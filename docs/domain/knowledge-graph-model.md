# 知识图谱模型

## 1. 目标

知识图谱是课程编排、题目生成、Boss 组题、掌握度计算和补课路径的唯一事实来源。

图谱不直接复制教材结构，只表达能力、前置关系和掌握标准。

## 2. 层级

```text
Subject
  -> Domain
    -> Knowledge Node
      -> Prerequisites
```

知识节点后续会映射到：

- 学习章节。
- 题族和题目。
- Boss 题目组成。
- 用户掌握度。
- 补救路径。

## 3. 节点字段

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 全局唯一 ID |
| name | 是 | 能力节点名称 |
| stage | 是 | 建议覆盖学段 |
| prerequisites | 是 | 前置节点 ID 列表 |
| mastery | 是 | 可观察的掌握标准 |
| item_families | 是 | 必须覆盖的题型 |
| boss_theme | 是 | 适合包装的 Boss 主题 |

## 4. ID 规范

```text
subject.domain.node
```

规则：

- 全小写。
- 使用英文和点号。
- ID 发布后不可改变。
- 节点名称可以修改，ID 不可修改。
- 删除节点时先迁移依赖，不能留下断链。

示例：

```text
math.arithmetic.multiplication_table
chinese.reading.inference
physics.electricity_magnetism.ohm_law
```

## 5. 依赖规则

- 前置依赖必须指向已存在节点。
- 图谱必须是有向无环图。
- 没有前置依赖的节点是入口节点。
- 用户必须掌握前置节点后，才能进入后继节点。
- 跨学科依赖默认不建立，避免课程编排复杂化。

## 6. 掌握标准

掌握标准必须可观察，不使用“理解”“熟悉”等无法验证的词。

不推荐：

```text
理解乘法
```

推荐：

```text
能把重复相加写成乘法
能解释乘法各部分意义
能从乘法口诀反推因数
```

## 7. 题型族

允许的标准题型族：

- 识别
- 判断
- 计算
- 应用
- 迁移
- 推理
- 建模
- 实验
- 分析
- 评价
- 创作
- 操作

各学科可以增加学科专用题型，但应保持命名稳定。

## 8. 图谱校验

CI 和内容发布前必须校验：

1. YAML 或 JSON 能正常解析。
2. 节点 ID 唯一。
3. 所有前置 ID 存在。
4. 图谱无环。
5. 每个节点有至少一个掌握标准。
6. 每个节点有 `boss_theme`。
7. 每个节点至少有两个题型族。
8. 所有学科和领域 ID 唯一。
