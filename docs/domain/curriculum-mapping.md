# 年级与关卡编排

## 1. 目标

把知识图谱转换为每年级 10 个小关。

固定游戏结构：

```text
年级世界 -> 10 个小关 -> 3 到 5 个章节 -> Boss
```

## 2. 输入

- 学段和年级。
- 学科知识图谱。
- 节点前置依赖。
- 节点建议学段。
- 节点预计学习时长。
- 节点题目难度。
- 用户掌握度，可选。

## 3. 输出

每个小关包含：

- 小关名称。
- Boss 主题。
- 3 到 8 个目标节点。
- 必要前置节点。
- 3 到 5 个章节。
- 章节顺序。
- Boss 题目组成。

## 4. 编排步骤

1. 按学段筛出候选节点。
2. 补入必要前置节点。
3. 按依赖关系构建子图。
4. 对节点估算学习时长。
5. 按主题和依赖聚合为里程碑。
6. 将里程碑数量校准为 10。
7. 为每个里程碑选择 Boss 主题。
8. 将节点拆为 3 到 5 个章节。
9. 生成章节短测和 Boss 题组。
10. 校验前置顺序、总时长和题量。

## 5. 固定容量

建议容量：

| 项目 | 目标 |
|---|---:|
| 每年级小关 | 10 |
| 每小关节点 | 3 到 8 |
| 每小关章节 | 3 到 5 |
| 每章节点 | 1 到 3 |
| 每章时长 | 3 到 8 分钟 |
| 每小关总时长 | 25 到 45 分钟 |
| Boss 题量 | 8 到 12 |
| Boss 时长 | 6 到 12 分钟 |

## 6. 聚合规则

- 强依赖节点必须在同一小关或更早小关。
- 同一小关节点应能共享情境或 Boss 主题。
- 低难度节点可以合并，高难度节点应独立成章。
- 后续节点不能反向依赖未学习节点。
- 跨领域综合节点放入较晚小关。

## 7. 年级适配

年级是编排参数，不是知识图谱字段。

同一节点可以：

- 在较早年级作为直观体验出现。
- 在正式年级作为掌握目标出现。
- 在后续年级作为复习或迁移出现。

但每年级只保留核心节点，避免把整个学科塞进一个年级。

## 8. 编排校验

发布前检查：

- 前置节点已覆盖。
- 章节顺序与依赖一致。
- 每小关时长在范围内。
- Boss 覆盖目标节点和前置节点。
- 没有连续两道 2 分钟或 5 分钟题。
- 没有未解锁知识节点。
- 没有重复题目。
- 每道题有解析和错因标签。

## 9. 算法建议

MVP 使用确定性编排，不使用黑盒推荐。

推荐流程：

1. 语义聚类节点。
2. 用依赖图做拓扑排序。
3. 用学习时长做背包式分组。
4. 用人工规则修正主题和难度。
5. 教师审核后锁定版本。

后续可以加入自适应路径，但必须保持前置约束和掌握阈值。
