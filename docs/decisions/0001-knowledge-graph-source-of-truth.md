# ADR-0001：知识图谱作为唯一事实来源

## 状态

已接受。

## 背景

产品需要按能力前置关系组织课程，而不是按教材章节组织。年级、小关、章节和 Boss 都需要可重复编排，并支持后续跨学科扩展。

## 决策

使用原创知识图谱作为课程域的唯一事实来源。

知识图谱定义：

- 学科
- 能力领域
- 知识节点
- 节点之间的前置依赖
- 掌握标准
- 题型族
- Boss 主题

年级世界和每个年级的 10 个小关是图谱节点的编排结果，不是手工维护的独立课程结构。

## 后果

正面影响：

- 课程顺序可计算、可验证。
- 题目可以绑定知识节点，而不是绑定教材页码。
- 失败后可以精确定位缺失前置知识。
- 同一图谱可以生成不同地区或不同版本的学习路径。

代价：

- 必须维护节点 ID 和前置依赖质量。
- 必须有图形校验和内容审核流程。
- 编排引擎需要处理容量、前置关系、主题聚合和年级适配。
