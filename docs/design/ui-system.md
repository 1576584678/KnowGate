# KnowGate UI 系统

## 1. 视觉方向

**风格：** Claymorphism + Vibrant & Block-based + Micro-interactions

关键词：

- 任务地图
- 软 3D
- 清楚的状态块
- 友好的圆形和积木形
- 少量弹性反馈
- 低焦虑的学习节奏

视觉不追求儿童游戏的全屏卡通包装。它更像一张清晰的能力探索地图：有游戏对象和动作反馈，也有稳定的信息层级与可扫描状态。

避免：

- 全屏装饰性渐变背景。
- 大量悬浮卡片嵌套。
- 每个按钮都做弹跳或抖动。
- 只靠颜色区分锁定、正确、错误和完成。
- 成人财经式密集仪表盘。
- 表情符号替代系统图标。

## 3. 布局

标准内容宽度：

- 手机：全宽，16px 水平边距。
- 平板：最大 760px。
- 桌面：最大 1180px。

响应式：

| 宽度 | 结构 |
|---|---|
| 375px | 单列，底部导航固定，地图纵向滚动 |
| 768px | 单列或 2 列详情，适合触控横向布局 |
| 1024px | 地图和详情分栏 |
| 1440px | 最大宽度居中，地图保留更多世界感空间 |

页面使用全宽区域和内容容器，不把每个页面区块都做成悬浮卡片。卡片只用于重复对象、模态框、战斗题板和确实需要框定的工具。

## 4. 组件

### 按钮

尺寸：

- 主按钮：最小高度 48px。
- 次按钮：最小高度 44px。
- 图标按钮：视觉 40px，命中区域至少 44x44px。

类型：

- 主按钮：学习蓝底白字。
- 次按钮：白底、蓝色边框和蓝色文字。
- 危险动作：只在退出、删除或清空时使用红色。
- 锁定按钮：保留形状但降低对比，并提供原因。

按下反馈：

- 按下时向 `translateY(1px)`，不改变布局尺寸。
- 150 至 220ms 过渡。
- 键盘焦点使用 3px 可见焦点环。

### 关卡节点

每个节点包含：

- 序号或主题图形。
- 状态图标。
- 文本状态。
- 星级或掌握度。

节点不能只靠颜色表示状态。已完成必须有对勾，锁定必须有锁形图标，进行中必须有当前标记。

### 进度

- 章节阶段：文字步骤条，例如 `2/6 概念`。
- 小关进度：数字或线性进度，例如 `3/4 章节完成`。
- 掌握度：0 至 100，显示数字和水平条。
- Boss 血量：分段条形或数字。
- Boss 距离：5 个位置点，同时显示 `Boss 还有 3 步`。

### Boss 题板

层级：

1. Boss 和距离轨道。
2. 题干。
3. 选项或输入。
4. 时间、提示、草稿和连击。

选项必须：

- 使用整行按钮，最小高度 52px。
- 支持键盘方向键或 Tab 导航。
- 答错后保留原选择并用图标和文字标记。
- 反馈区域使用 `aria-live="polite"`。

### 计时器

- 使用数字和环形或线性进度双重表达。
- 时间低于 25% 时使用图形和文字提示，不只变色。
- 学习模式显示 `不影响胜负`。
- 提供暂停按钮。

### 掌握度卡片

显示：

- 节点名称。
- 掌握度数字。
- 状态：`未掌握`、`初步掌握`、`已掌握`。
- 最近练习和下次复习。
- 一个针对性行动。

避免只显示分数。家长视图也使用掌握度而不是排名。

## 5. 地图与游戏对象

地图对象来自项目的 `boss_theme`，例如：

- 数字森林
- 数位城
- 分数裂谷
- 小数回廊
- 精度之塔
- 比例天平

视觉规则：

- 每个小关有一个可识别形状或地标。
- 路径连接节点，但不会覆盖交互目标。
- 当前关卡最醒目，锁定关卡降低视觉权重但仍可读。
- 地图背景是明确的地形表面，不使用装饰性光斑或模糊渐变球。
- 图形使用 SVG 或 CSS 构建，便于后续统一换肤和响应式调整。

## 6. 动效

| 事件 | 动效 | 时长 |
|---|---|---|
| 页面进入 | 轻微淡入和上移 | 220ms |
| 地图节点出现 | 节点错峰 40 至 60ms | 300 至 450ms |
| 答对 | 题板确认、Boss 轻微受击 | 180 至 240ms |
| 答错 | 距离点推进、错误标记 | 220 至 300ms |
| 胜利 | Boss 退场、星级和掌握度出现 | 500 至 700ms |
| 补课路径 | 节点按前置顺序逐一亮起 | 300 至 450ms |

约束：

- 动效表达状态变化，不做纯装饰循环。
- 避免同时动画宽度、高度和布局位置。
- 尊重 `prefers-reduced-motion`。
- 不依赖动效传达唯一信息。
- 结算动画不超过 700ms，之后必须能稳定阅读。

## 7. 图标与插画

- 使用同一套 SVG 图标，优先 Lucide 风格。
- 图标按钮必须有可访问名称。
- 文本旁装饰图标从辅助技术中隐藏。
- Boss 和地图地标使用项目自有的 SVG/CSS 游戏对象。
- 不使用 emoji 作为导航、状态或系统控制图标。

## 8. 响应式与安全区

- 顶部和底部固定区域预留安全区。
- 滚动列表底部留出底部导航和操作栏高度。
- 375px 下不出现水平滚动。
- 竖屏和横屏都保持当前任务可见。
- 平板和桌面增加内容边距，不让长文本横跨整个屏幕。
- Boss 战斗优先保证题干和选项在首屏内。

## 9. 无障碍验收

- 正常文本对比度至少 4.5:1。
- 图标和边界等非文本对比至少 3:1。
- 所有关键动作支持键盘。
- 焦点环清晰且不被固定栏遮挡。
- 支持系统文字放大。
- 支持减少动态效果。
- 倒计时、自动推进和动画可暂停或关闭。
- 表单错误靠近字段，多个错误提供错误摘要。
- 颜色不是唯一的状态表达。

## 10. 交付规则

实现页面时：

1. 先读取 `design-system/knowgate/MASTER.md`。
2. 如果存在对应页面规则，优先使用页面规则。
3. 使用语义令牌，不在组件里散落十六进制颜色。
4. 先实现任务闭环，再添加装饰性动效和插画。
5. 在 375px、768px、1024px 和 1440px 检查布局。
6. 在键盘、减少动态效果和放大文字条件下完成一次任务。
