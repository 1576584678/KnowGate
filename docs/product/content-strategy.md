# 内容策略

## 1. 内容原则

- 只做核心能力，不复制教材全量内容。
- 先保证顺序正确，再追求题量。
- 每个知识点必须有掌握标准和错因标签。
- 每道题必须绑定知识节点。
- 不依赖教材、教辅或商业题库的未授权内容。

## 2. 内容层级

```text
学科
  -> 能力领域
    -> 知识节点
      -> 章节
      -> 题族
      -> Boss
```

## 3. 章节模板

每章固定包含：

1. 钩子：生活情境、图形、反例或快速演示。
2. 概念：只讲一个核心概念。
3. 范例：展示思考过程。
4. 跟做：用户完成一个步骤。
5. 独立练习：用户独立完成。
6. 短测：2 到 4 题。

章节目标时长 3 到 8 分钟。

## 4. 题族

每个知识节点至少覆盖：

- 识别：确认符号、概念、事实和结构。
- 判断：识别正确与错误，发现常见误区。
- 计算：执行定义、规则或步骤。
- 应用：在情境中使用知识。
- 迁移：变化条件、逆向推理、跨节点综合。

## 6. 出题方式

### 参数化生成

适用：

- 算术
- 分数、小数和比例
- 方程
- 几何计算
- 物理计算
- 化学计量

生成器必须：

- 有可复现随机种子。
- 自动校验答案。
- 支持干扰项生成。
- 支持难度参数。
- 输出完整解析。
- 经过规则测试。

### 教师原创

适用：

- 语文阅读。
- 英语语篇。
- 历史材料分析。
- 地理综合题。
- 道法情境题。
- 主观题和开放题。

### AI 辅助

AI 可以：

- 生成变式。
- 生成干扰项。
- 生成解析草稿。
- 提取知识点。
- 标记潜在错因。

AI 不可以：

- 直接发布核心题目。
- 替代教师审核。
- 在缺乏来源的情况下生成历史事实。
- 自动决定主观题最终分数。

## 7. 来源与版权

允许：

- 原创内容。
- 公共领域内容。
- CC0、CC BY 等开放许可内容，并核验商用及改编权限。
- 已购买明确商业授权的第三方内容。

禁止：

- 复制教材正文、栏目和例题。
- 抓取商业题库。
- 使用未授权试卷。
- 使用“某教材同步”等未经许可的宣传。

每项内容必须记录来源台账：

- 来源名称。
- 来源地址或文件。
- 许可证。
- 是否允许商用。
- 是否允许改编。
- 归属要求。
- 有效期。
- 审核人。

## 8. 质量门槛

题目发布前必须通过：

1. 知识点绑定检查。
2. 答案正确性检查。
3. 解析完整性检查。
4. 难度和时间档检查。
5. 歧义和双重答案检查。
6. 敏感内容检查。
7. 版权来源检查。
8. 教师审核。

## 9. 内容版本

- 已发布的题目不原地修改答案。
- 修改题目时创建新版本。
- 进行中的战斗固定使用开始时的版本。
- 复盘报告记录当时使用的题目版本。

## 10. 错因体系

每个学科维护自己的错因标签。

数学示例：

- 概念混淆。
- 运算顺序错误。
- 进位退位错误。
- 单位换算错误。
- 建模错误。
- 计算粗心。

语文示例：

- 信息定位错误。
- 概括范围过大。
- 概括范围过小。
- 推断无文本依据。
- 修辞作用分析不完整。

错因标签用于补课、家长报告和题目推荐，不用于公开排名。
